# agent-timeline

このリポジトリはアーカイブしました。
agent-timeline は [malanjp/skills](https://github.com/malanjp/skills) の [plugins/agent-timeline](https://github.com/malanjp/skills/tree/main/plugins/agent-timeline) に移り、開発もそちらで続けます。

Claude Code のターミナルで次を実行して導入します。

```text
/plugin marketplace add malanjp/skills
/plugin install agent-timeline@malanjp
```

このリポジトリのマーケットプレイスから入れた場合は、`/plugin uninstall agent-timeline@agent-timeline` で外してから入れ直してください。
